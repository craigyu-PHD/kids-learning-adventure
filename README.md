# 星際共學基地｜兒童美語教學網站

給家庭共學使用的 18 週幼兒學習網站。主要使用者是爸爸、媽媽或其他照顧者，由大人控制影片節奏，帶領多名小朋友一起完成唱跳、觀看、暫停複誦、回看、互動遊戲與跨域任務。

## V1 內容

- 18 週 × 每週一至週五，共 90 個學習日。
- 每天兩節活動單元，每節約 30 分鐘；標準完成時間 45–60 分鐘。
- 90 天共 180 個活動單元。
- 英文為主軸，穿插數學、ㄅㄆㄇ、生活、自然探索與總複習。
- YouTube 教材以 Super Simple Songs、快樂斑比 HAPPY BAMBI 為主。
- 每節課都包含照顧者腳本：暖身、首次觀看、暫停提示、複誦、回看、互動遊戲、分齡挑戰、收尾。
- 支援多名小朋友，並可每天重新勾選實際參與者。
- 每位小朋友獨立累積 XP、金幣、任務與完成進度。
- 首頁提供 90 天學期日曆、完成狀態、進度條與階段里程碑。
- 課後 30 秒紀錄：完整看／片段看／跳過、投入程度、簡短備註。
- Light / Dark / System 三種顯示模式。
- 學期起始日可調整，90 個平日自動重新排程。
- V1 不使用登入、PIN 或生成式 AI；學習資料存於瀏覽器 localStorage。
- 可匯出學習紀錄 JSON 備份。

## 教學設計

網站採「影片是素材，家長是節奏控制員」原則，不把 30 分鐘單元設計成 30 分鐘連續被動觀看。課程使用螺旋式複習，核心字彙會在不同主題與任務中再次出現。

4 歲與 6 歲可一起上同一主題，但每節都提供初階與進階任務。例如初階以指認、動作、單字為主；進階逐步加入完整句、問答、比較與小老師角色。

```bash
npm run build
npx tsc --noEmit
```
