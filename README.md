# 星際共學基地｜兒童美語教學網站 V2

給家庭共學使用的 18 週幼兒學習網站。主要使用者是爸爸、媽媽或其他照顧者，由大人控制影片節奏，帶領多名小朋友一起完成唱跳、觀看、暫停複誦、回看、互動遊戲與跨域任務。

## V2 主要更新

- 首頁學期日曆改為月份分組的緊湊排版，直接顯示月份、日期、Day 與完成狀態。
- 每節課的暖身歌改為食物／水果主題輪替，主課仍保留 18 週多元內容。
- 「今日重點」改為圖像單字、口說句型與身體／操作任務三種入口，更適合 4 歲與 6 歲共同學習。
- 常見重要中文標題加入注音輔助，例如「小小探險隊」「學期日曆」「今日重點」「照著做就能上課」「互動任務」「完成本節」「課後紀錄」。
- 放大家長教案、暫停提示、互動任務與課後紀錄文字。
- 原創角色頭像取代 emoji，支援星光勇者、雷霆守衛、鋼甲巨衛、極速騎士、暴龍機兵、深海先鋒。
- 頭像依 XP 自動分四階進化，逐步增加裝甲、翼片、能量光環與最高階徽冠。
- 新增五套原創冒險主題：星能英雄、機甲出擊、迷你戰車、極速賽道、奇獸夥伴。套用後會改變背景、介面色系、遊標與點擊特效。
- 增加全站背景動畫、點擊粒子、領獎動畫與指定日隱藏彩蛋。
- XP／金幣改為「由完成紀錄推導」，不再直接累加數字，避免重複點擊或同步造成分數漂移。
- 互動任務新增清楚的「完成標準」與領獎按鈕；兩個任務完成後才可通關該節。
- V2 支援 Vercel 私有 Blob 雲端同步，可用家庭同步碼在不同裝置載入同一份學習進度。

## 完整課程

- 18 週 × 每週一至週五，共 90 個學習日。
- 每天兩節活動單元，每節約 30 分鐘；標準完成時間 45–60 分鐘。
- 90 天共 180 個活動單元。
- 英文為主軸，穿插數學、ㄅㄆㄇ、生活、自然探索與總複習。
- YouTube 教材以 Super Simple Songs、快樂斑比 HAPPY BAMBI 為主。
- 每節課都包含照顧者腳本：暖身、首次觀看、暫停提示、複誦、回看、互動遊戲、分齡挑戰、收尾。
- 支援多名小朋友，並可每天重新選擇實際參與者。
- 課後 30 秒紀錄：完整看／片段看／跳過、投入程度、簡短備註。

## V2 獎勵引擎

V2 不再把 XP 與金幣本身當成可修改狀態。系統只保存：

- 已完成任務 ID
- 已完成單元 ID
- 已完成學習日 ID
- 已領取彩蛋 ID

畫面上的 XP 與金幣每次都依上述紀錄重新計算，因此重新整理、跨裝置同步或撤銷任務都不會讓數字自行漂移。

## 雲端同步

V2 的正式 Vercel 站可啟用「家庭同步碼」：

1. 主要裝置按「啟用雲端同步」，系統產生一組高熵家庭同步碼並上傳目前資料。
2. 其他手機、平板、Mac 或 Windows 在設定頁輸入同一組同步碼，即可下載相同進度。
3. 啟用後，設定、進度、每日參與名單與課後紀錄會在異動後自動同步。
4. 本機 localStorage 仍保留一份資料，網路暫時失敗時不會失去目前裝置的紀錄。

同步碼本身就是家庭資料的存取鑰匙；V2 沒有另外要求帳號、PIN 或密碼，因此同步碼請只在自己的裝置之間分享。

後端使用 Vercel Function `/api/state` 搭配 private Vercel Blob。Blob 憑證只存在 Vercel 專案環境變數與本機被 `.gitignore` 排除的環境檔，不會打包到瀏覽器或提交到 Git。

## 開發與驗收

```bash
npm install
npx tsc --noEmit
npm run build
npx vercel build --prod
```

目前 TypeScript 固定為 5.9.3，避免 Vercel Functions builder 與 TypeScript 7 的相容性問題。
