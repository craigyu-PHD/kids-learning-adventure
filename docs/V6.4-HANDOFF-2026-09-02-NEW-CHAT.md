硬規則：

- 不得把這些 UI concept 圖裁切後冒充正式 wearable Hero。
- 不得因工具誤判改用 CSS / SVG / Emoji / hue-rotate 等低品質替代。
- 正式 Hero 必須真的是「原網站角色身份 + 指定裝備 + 透明背景完整人物」。

這批漂亮生成圖應保留為：

- V6.4 Lookbook
- Art Bible reference
- Shop visual direction
- Theme / rarity / world-item concept

但不要標記為 Art Acceptance PASS。
