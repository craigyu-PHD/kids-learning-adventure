## 本版核心變更

### 一、V6 CSS 架構建立

全新 `src/styles/` 層疊體系，取代直接修改 `v40.css` 的舊方式：

```
src/styles/index.css        ← 唯一入口
  ├── tokens.css            ← V6 Design Token（顏色/字級/間距/圓角/陰影）
  ├── reset.css
  ├── legacy-compat.css     ← 封裝所有 legacy CSS
  ├── layout.css            ← 頁面 shell & 全域修正
  ├── components/
  │   ├── header.css        ← Header / Controls（V6 自有）
  │   ├── dashboard.css     ← Dashboard 所有面板（V6 自有）
  │   └── report.css        ← 報表 / Learning Mastery（V6 自有）
  ├── motion.css
  ├── accessibility.css
  └── responsive.css        ← 四級斷點（XL / Desktop / Tablet LS / Tablet PT）
```

### 二、字型階層與字級修正

| 項目 | V5.3.1 | V6.0.0 |
|------|--------|--------|
| Lesson Card Header | 11px | **12px** |
| Lesson Card Title | 14px | **17px** |
| Lesson Card CTA | 13px | **15px / 44px touch target** |

| Calendar 日期數字 | 9px | **12px** |
| Evolution stage span | 9px | **12px** |

| Parent Calendar day/small | 10px | **12px** |

### 三、font-weight 全站掃清

v40.css + v30.css 共 **33 處** `font-weight:850/900/950/1000` 全數改為 400–800 範圍內的合法值。  
瀏覽器不再合成 faux-bold，Chrome / Safari / Android 渲染一致。

### 四、border-radius Token 化

```css
--radius-sm:  10px
--radius-md:  16px
--radius-lg:  22px
--radius-pill: 999px
```

Lesson Card 18→16px、History Panel 28→22px、Daily/Calendar Panel 28→22px、各類 article 18/20→16px。

### 五、Layout 修正

- 三欄外框 `overflow:hidden` → **`overflow:clip`**（不再遮蓋 layout bug）
- 三欄 border：2px → **1.5px**，移除 ambient inset glow
- Player card `overflow:hidden` → **`overflow:visible`**
- Panel box-shadow 統一走 token

### 六、Header 改善

- Controls 由單列 → **雙列**（Parent Status 上 / Themes+Sound 下）
- Controls 固定 **340px** 寬，不再壓縮 nav
- Logo `max-height: 82px`，避免各主題圖片差異導致跳版
- Theme buttons 52 → **44px**（與 touch target 同規）

### 七、響應式四級斷點

| 斷點 | 範圍 | 佈局 |
|------|------|------|
| XL | ≥1480px | 三欄全展開（預設） |
| Desktop | 1280–1479px | 左 240px / 中 1fr / 右 320px，Calendar fluid |
| Tablet LS | 1024–1279px | 左 240px / 中 1fr，右欄移到第二列 |
| Tablet PT | 768–1023px | 單欄堆疊 |

### 八、英文標籤全面中文化

**Dashboard.tsx**：移除 `EVOLUTION`、`ACHIEVEMENTS`、`AI LEARNING BUDDY`  
**SecondaryViews.tsx**：移除 `BADGE COLLECTION`、`PLAYER`、`COIN SHOP · NO REAL MONEY`、`SHOPPING FOR`、`PARENT ANALYTICS · PIN PROTECTED`、`LEARNER`、`THIS WEEK`、`THIS MONTH`、`INTERACTION ACCURACY`、`MOST MISSED WORD`、`18 WEEKS · 90 DAYS`、`ADVENTURE TEASER`  
**LessonQuest.tsx**：移除 `SENTENCE PATTERN`、`YOUNGER/OLDER`、`SPECIAL BONUS`、`Preview Only`、`Mission Complete!`、`SPEAKING PRACTICE`、`DAILY REVIEW`、`QUICK CHECK`、`Listen`  
**Report footer**：移除工程字樣 `360 unique`、`PIN protected`，改為中文友善文字

保留的英文標籤（具功能性定位）：`STAGE 1–9`、`WEEK 01–18`、`PLAYER TEAM`、`TODAY MISSION`、`SEMESTER MAP`、`XP`、`Coins`、`Stars`、`Gems`

### 九、狀態列文字兒童化

`Server verified` / `360 unique` → `☁ 雲端已同步` / `🛡 今日任務已確認` / `▶ 教材準備完成`

### 十、Lesson Card Song 資訊分層

`課前歌曲：XXX` 單行 → 兩行：`課前歌曲`（11px/muted label）+ 歌名（12px/blue name）
