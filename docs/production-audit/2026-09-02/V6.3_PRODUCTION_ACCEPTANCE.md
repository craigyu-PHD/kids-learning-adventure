## Remote Preview QA Timing Correction

The first Production all-item preview run returned 216/252 because the QA harness used a fixed 35ms delay before checking newly selected Ship / Robot / Card preview images. Direct Production requests confirmed all V6.3 preview assets were present and returned HTTP 200.

The tracked QA harness was hardened to wait for `img.complete && naturalWidth > 0` with a bounded timeout. The full Production rerun then passed 252/252 with zero console errors and zero page errors. This was a QA timing correction, not a runtime asset change.
