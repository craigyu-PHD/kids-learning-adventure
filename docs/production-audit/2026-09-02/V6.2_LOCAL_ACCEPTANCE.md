## Hybrid Avatar V2

Implemented on the existing `AvatarRenderer`, `AvatarWardrobe`, `shopService`, and `shopLedger` architecture.

Supported render modes:

- `full-skin`
- `aligned-overlay`
- `split-overlay`
- `standard-effect`
- `world`

Wearable overlays use fixed 1024×1536 transparent assets. Current feature-owned CSS contains no direct wearable top/left/scale magic-number selectors. Legacy compatibility selectors remain preserved in historical CSS but are no longer emitted by the current renderer.

Completed wearable conversion in this release includes:

- 3 free Starter items: hat / glasses / headphones
- selected legacy hat / glasses / headphones
- `hair-comet`
- `trail-backpack` split overlay
- `hero-cape` split overlay
- existing `outfit-racer` full skin
- existing validated effects/world items

V6.2 explicitly does **not** claim that all historical wearables have been converted. Unfinished items remain preserved and are limited to `新裝備準備中` in Child Mode.
